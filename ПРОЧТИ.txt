ПРОВЕРКА ПУБЛИКАЦИЙ — версия 0.7.3 от 14.10.2026

Что это: веб-страница. Показывает факты о публикациях и авторах; выводов не делает.
  1. Список публикаций (снимок или текст) → по каждой: квартиль, Белый список, показатель, первый и corresponding автор, ссылки;
     возможные дубли в списке (одинаковый DOI, название, препринт и статья, тезисы и статья).
  2. Автор (ФИО кириллицей или латиницей, ORCID, Scopus ID, ResearcherID или строка идентификаторов) → блок «Профили автора»
     со всеми ссылками и все его публикации: corresponding — да / нет / не указан, организация автора и сверка с организацией из заявки.
  3. Несколько авторов сразу → сводная таблица и публикации каждого.
  Фильтры: квартиль и уровень Белого списка («или»), годы, corresponding, показатель «от …», организация («и»).
Нужен интернет: статьи — Crossref, авторы и организации — OpenAlex и реестр ORCID. Квартиль, показатель и Белый список — из справочников.

Две сборки:
  «Проверка_публикаций_0.7.3.html» — одна страница со всем внутри; открывается двойным щелчком, без сервера.
  папка «Сайт» — то же для выкладки на Netlify: страница маленькая, справочники и распознавание отдельными файлами
  (загружаются один раз и кешируются браузером), страница закрыта от поисковиков (noindex, robots.txt).
  Выкладка: app.netlify.com → проект proverka-publikaciy → Deploys → перетащить папку «Сайт» в поле загрузки.
  Адрес: https://proverka-publikaciy.netlify.app

С чего начать: «Связь и настройки» → «Проверить связь», затем «Самопроверка на известных статьях».
На настоящих базах проверены связь, самопроверка и поиск статей по тексту; поиск автора, профили, организации,
группа — только на подставных ответах. Ссылки-поиски Google Scholar, Semantic Scholar, ORCID, Scopus, WoS, eLibrary
составлены по известному виду адресов (проверить их отсюда нельзя); ResearchGate проверен.

Обновление справочников (раз в год для SCImago, по мере выхода для Белого списка):
  python3 mkdata.py journalrank_ДАТА.json scimagojr_2021.csv scimagojr_2022.csv … (все годы сразу)
  npm install && python3 build.py
Ключи (с 0.7.3): если рядом с build.py лежит openalex_key.txt (ключ OpenAlex) или orcid_token.txt (токен ORCID /read-public),
  они встраиваются в страницу и видны в её коде. Сами файлы в исходники и в текст проекта не входят — хранятся у Германа.
  Сейчас встроен ключ OpenAlex; токен ORCID — после ответа ORCID об условиях использования.
GitHub (с 14.10.2026): репозиторий NEMOL8/proverka-publikaciy (закрытый), Netlify публикует папку site/ из ветки main.
  Новая версия: python3 build.py && rm -rf site && cp -r dist/site site && git add -A && git commit && git push — сайт обновится сам.
